# Terminal Roguelike (C#)
> A classic text-based roguelike game running entirely in the console, built as a university project. 

![Status: Work in Progress](https://img.shields.io/badge/Status-Work_in_Progress-yellow)
![Language: C#](https://img.shields.io/badge/Language-C%23-blue)

## About the Project
This project is an exploration of procedural generation and turn-based mechanics using **C#**. It is currently in the early stages of development (started recently), focusing on building the core engine, grid movement, and basic terminal rendering.

## Current Status & Roadmap
*This project is heavily under development.*

**Currently Implemented:**
- [x] Basic terminal grid rendering
- [x] Player movement (Arrows)
- [x] Basic map boundaries
- [x] Collision detection (walls)
- [x] Basic enemies and turn-based combat
- [x] Interaction thru the key E 

**Planned Features:**
- [ ] Procedural dungeon generation (rooms and corridors)
- [ ] Better enemies
- [ ] Items implementation
- [ ] Loot and inventory system
- [ ] Win/Loss conditions
- [ ] Movement switch to 8 directions (Maybe, probably not)

## Tech Stack
- **Language:** C# (.NET)
- **Environment:** Console / Terminal

## How to Run
Since this is a console application, you can run it using the standard .NET CLI.
